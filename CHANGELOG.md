# Changelog - CryptoBot

## [1.1.0] - 2026-11-11

### 🔒 Security & Validation (High Priority)

#### ✅ Input Validation
- **Защита от DoS атак**: Ограничение максимальной суммы (1 млрд)
- **Валидация отрицательных чисел**: Блокировка отрицательных сумм
- **Валидация нуля**: Блокировка нулевых значений
- **Ограничение точности**: Максимум 8 знаков после запятой

#### ✅ API Error Handling
- **Retry-логика**: Автоматические повторные попытки при ошибках сети (exponential backoff)
- **HTTP 429 обработка**: Корректная обработка rate limiting от API
- **Безопасный XML парсинг**: Проверка каждого элемента на None перед обращением к `.text`
- **Валидация курсов**: Проверка курсов от API на корректность (положительные значения)
- **Проверка пустых ответов**: Валидация длины ответа от API перед парсингом

#### ✅ Database Security
- **Минимизация данных**: Хранится только user_id (соответствие GDPR)
- **Параметризованные запросы**: Защита от SQL injection
- **Нет личных данных**: Username, phone, email не хранятся

### 📊 Technical Details

**Новые функции в handlers.py:**
- `validate_amount()` — валидация пользовательского ввода
- `validate_rate()` — валидация курсов от API
- `retry_api_call()` — retry-логика с exponential backoff

**Улучшенные функции:**
- `get_cbr_rates()` — безопасный парсинг XML, обработка HTTP 429
- `get_btc_rate()` — проверка пустых ответов, валидация JSON
- `get_cbr_historical()` — безопасный парсинг исторических данных
- `handle_text_input()` — интеграция валидации в обработчик
