# Запуск тестов CryptoBot

Этот документ содержит инструкции по установке зависимостей и запуску автотестов для проекта CryptoBot.

---

## Установка зависимостей

Перед запуском тестов необходимо установить тестовые зависимости:

```bash
pip install -r requirements.txt
```

Это установит:
- `pytest` — фреймворк для тестирования
- `pytest-asyncio` — поддержка асинхронных тестов
- `pytest-cov` — измерение покрытия кода тестами

---

## Запуск тестов

### Запуск всех тестов

```bash
pytest tests/
```

### Запуск с подробным выводом

```bash
pytest tests/ -v
```

### Запуск конкретного тестового файла

```bash
pytest tests/test_suite.py
```

### Запуск конкретного тестового класса

```bash
pytest tests/test_suite.py::TestValidation
```

### Запуск конкретного теста

```bash
pytest tests/test_suite.py::TestValidation::test_validate_amount_positive_normal
```

---

## Измерение покрытия кода

### Запуск с измерением покрытия

```bash
pytest --cov=. --cov-report=term-missing tests/
```

### Генерация HTML-отчёта о покрытии

```bash
pytest --cov=. --cov-report=html tests/
```

HTML-отчёт будет создан в папке `htmlcov/`. Откройте файл `htmlcov/index.html` в браузере для просмотра детального отчёта.

### Настройка минимального порога покрытия

```bash
pytest --cov=. --cov-fail-under=80 tests/
```

Тесты завершатся с ошибкой, если покрытие ниже 80%.

---

## Полезные опции pytest

### Остановка на первой ошибке

```bash
pytest tests/ -x
```

### Запуск только последних упавших тестов

```bash
pytest tests/ --lf
```

### Показ всех выводов print()

```bash
pytest tests/ -s
```

### Запуск в тихом режиме (только итоги)

```bash
pytest tests/ -q
```

## Структура тестов

Тесты организованы по категориям:

### TestValidation
Тесты функций валидации (`validate_amount`, `validate_rate`):
- Положительные и отрицательные сценарии
- Граничные значения
- Обработка ошибок

### TestDatabase
Тесты работы с базой данных:
- Инициализация БД
- Добавление записей
- Получение истории с пагинацией
- Подсчет записей и страниц

### TestParsing
Тесты парсинга пользовательского ввода (`parse_currency_input`):
- Различные форматы ввода
- Символы валют
- Русские и английские названия
- Обработка некорректного ввода

### TestAPIIntegration
Интеграционные тесты API (с моками):
- Успешные запросы к ЦБ РФ и CoinGecko
- Обработка ошибок сети
- Невалидные данные
- Пустые ответы

### TestHelpers
Тесты вспомогательных функций:
- Форматирование курса валюты

## Примеры использования

### Быстрая проверка перед коммитом

```bash
pytest tests/ -v --tb=short
```

### Полная проверка с покрытием

```bash
pytest tests/ -v --cov=. --cov-report=html --cov-report=term-missing
```

### Запуск только unit-тестов

```bash
pytest tests/ -m unit
```

### Запуск только асинхронных тестов

```bash
pytest tests/ -m asyncio
```

## Решение проблем

### Ошибка "ModuleNotFoundError"

Убедитесь, что запускаете pytest из корневой папки проекта, где находится `requirements.txt`.

### Ошибки с асинхронными тестами

Убедитесь, что установлен `pytest-asyncio`:
```bash
pip install pytest-asyncio
```

### Ошибки с базой данных

Тесты используют временную БД, которая создаётся и удаляется автоматически. Если возникают проблемы, убедитесь, что:
- У вас есть права на запись во временную папку
- Файл `currency_bot.db` не заблокирован другим процессом

## Continuous Integration (CI)

Для интеграции с CI/CD пайплайнами используйте команду:

```bash
pytest tests/ --cov=. --cov-report=xml --cov-fail-under=80
```

Это создаст XML-отчёт о покрытии для инструментов вроде Codecov или Coveralls.
