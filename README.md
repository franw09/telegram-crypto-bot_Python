# 🤖 Telegram Currency Bot

Telegram бот для отслеживания курсов валют в режиме реального времени.

---

## 📋 Что умеет бот

- 💱 Получать актуальные курсы валют через внешнее API
- 📊 Просматривать графики изменения курсов
- ⚡ Настраивать уведомления о изменениях
- 💾 Сохранять историю запросов в базе данных

---

## 🚀 Быстрый старт (2 простых шага)

**💡 ВАЖНО:** При первом запуске `venv-start.bat` автоматически создаст виртуальное окружение и установит все зависимости!

### Шаг 1: Получите токен бота

1. **Получите токен:**
   - Откройте Telegram
   - Найдите @BotFather
   - Отправьте `/newbot`
   - Скопируйте токен

### Шаг 2: Настройте токен бота

1. Откройте файл `.env.example` в блокноте
2. Замените `YOUR_BOT_TOKEN_HERE` на ваш токен от @BotFather:
   ```
   BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
   ```
3. Сохраните файл (Ctrl+S)
4. Переименуйте файл `.env.example` в `.env`

### Шаг 3: Запустите установку и бота

1. Дважды кликните на файл `venv-start.bat`
   - Создастся виртуальное окружение
   - Установятся все зависимости автоматически
2. После завершения установки откройте терминал в папке проекта
3. Запустите бота:
   ```bash
   python main.py
   ```

Готово! Бот работает! 🎉

## 📦 О файле requirements.txt

В файле `requirements.txt` перечислены все библиотеки которые нужны боту:

```
aiogram==3.13.1      # Telegram Bot API
aiohttp==3.10.10     # HTTP запросы к API валют
python-dotenv==1.0.1 # Чтение .env файла
aiosqlite==0.20.0    # База данных
matplotlib==3.9.2    # Построение графиков
numpy==2.1.3         # Математика
```

**Команда для установки:**
```bash
pip install -r requirements.txt
```

Одна команда установит всё автоматически!

## 🐛 Решение проблем

### Python не найден
```bash
# Установите Python с python.org
# При установке поставьте галочку "Add Python to PATH"
```

### Ошибка при установке библиотек
```bash
# Обновите pip и попробуйте снова
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### Бот не отвечает
- Проверьте токен в `.env`
- Убедитесь что `python main.py` запущен
- Проверьте интернет соединение
